# WebdriverIO 8 Cucumber

This module demonstrates how Serenity/JS integrates with the legacy WebdriverIO v8 using Cucumber.js as the test runner.

## Why this module?

WebdriverIO v8 remains in use by teams that haven't yet migrated to v9. Serenity/JS maintains backward compatibility to ensure existing test suites continue to work without modification.

## Features demonstrated

- Passing scenario reporting through WebdriverIO v8's Cucumber integration
- Native Cucumber formatter support alongside Serenity/JS reporting
- Gherkin scenarios executed via WebdriverIO v8 with full browser automation
