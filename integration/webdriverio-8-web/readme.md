# WebdriverIO 8 Web

This module demonstrates Serenity/JS web testing capabilities using the legacy WebdriverIO v8 as the browser automation tool.

## Why this module?

WebdriverIO v8 remains in use by teams that haven't yet migrated to v9. Serenity/JS maintains backward compatibility to ensure existing test suites continue to work without modification.

## Features demonstrated

- PageElement interactions via the `@serenity-js/web` abstraction layer
- WebDriver and DevTools protocol support
- BrowseTheWebWithWebdriverIO ability implementation for v8
- Same portable web specs as Playwright and WebdriverIO v9
