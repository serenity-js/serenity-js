# Using Protractor with Jasmine and Serenity/JS (Legacy)

This module demonstrates how Serenity/JS integrates with the legacy Protractor framework using Jasmine as the test runner.

## Why this module?

Protractor has been deprecated, but Serenity/JS continues to support it to help teams migrate to Playwright or WebdriverIO at their own pace. The Screenplay Pattern abstractions remain portable across all supported tools.

## Features demonstrated

- Passing and failing scenario reporting through Protractor's Jasmine integration
- Restarting browser between tests for test isolation
- Screenplay Pattern integration within Protractor/Jasmine tests
- Filtering tests using Jasmine's `grep` pattern
