# Protractor Cucumber

This module demonstrates how Serenity/JS integrates with the legacy Protractor framework using Cucumber.js as the test runner.

## Why this module?

Protractor has been deprecated, but Serenity/JS continues to support it to help teams migrate to Playwright or WebdriverIO at their own pace. The Screenplay Pattern abstractions remain portable across all supported tools.

## Features demonstrated

- Passing scenario reporting through Protractor's Cucumber integration
- Filtering Cucumber scenarios by line number
- Native Cucumber formatter support alongside Serenity/JS reporting
- Gherkin scenarios executed via Protractor with Angular-aware browser automation
