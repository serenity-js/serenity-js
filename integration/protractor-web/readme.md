# Web Testing with Protractor (Legacy)

This module demonstrates Serenity/JS web testing capabilities using the legacy Protractor framework as the browser automation tool.

## Why this module?

Protractor has been deprecated, but many Angular teams still have existing test suites built on it. Serenity/JS provides a migration path — the same `@serenity-js/web` abstractions work across Protractor, Playwright, and WebdriverIO, allowing teams to migrate incrementally.

## Features demonstrated

- PageElement interactions via the `@serenity-js/web` abstraction layer
- BrowseTheWebWithProtractor ability implementation
- Same portable web specs as Playwright and WebdriverIO
- Angular-specific waiting and synchronisation via Protractor
